# 给 LTZ 博客接入 AI / 云服务推广广告

推荐文章下方的左侧广告位已准备好。它是一个固定商家推广卡，与 Google AdSense 分开配置。桌面展示纵向卡片，手机展示紧凑卡片；文章的三列排版不变。

目前没有个人推广链接，`src/config.ts` 中的 `SidebarSponsor.enable` 为 `false`。正式网页不会显示示例广告或空白占位，也没有接入返佣。

## 推荐先申请：阿里云云大使

你的博客有云迁移、数据库和部署文章，云服务与阅读内容比较匹配。官方云大使页面也列有 Qoder 等 AI 产品推广活动，可在加入后查看当前可推广产品。

1. 打开 [阿里云云大使](https://dashi.aliyun.com/)，用自己的阿里云账号登录。
2. 点击“立即加入”，按页面要求加入返利计划、完成实名认证。个人身份信息和收款信息只在官网填写。
3. 进入“云大使管理平台 → 推广素材 → 官方热门素材”，挑一个与博客相关的活动。
4. 复制**自己的专属推广链接**。官方说明该链接带有 `userCode`；不要使用他人的推广链接，也不要自己猜这个值。
5. 同时保存后台提供的广告图片，或提供可以公开使用的品牌名称、活动文案。图片的使用范围和有效期以该活动要求为准。
6. 将公开推广链接和图片交给网站维护者即可接入；不需要提供密码、API 令牌或身份证信息。
7. 接入后在后台查看关联客户与返利记录。访客点链接并不直接产生收益；还需要满足关联、下单和活动规则。

具体产品范围、奖励与结算以你登录后的活动规则为准。不要将官网宣传的“最高返佣”当作所有订单的固定比例。

## 海外云服务备选：DigitalOcean

[DigitalOcean Affiliate Program](https://www.digitalocean.com/affiliates) 有官方申请入口，并提供推广链接、横幅和活动素材。适合以后写海外部署、开发者工具等内容时使用。

申请时从官方页面进入 `Become an affiliate`，以跳转后的申请平台和资格要求为准。官方页面当前写明，新付费用户的月消费可按 10% 计算佣金、持续一年；产品和订单资格仍需按具体协议核对。

这是 Affiliate Program；不要将账户里的普通推荐额度当成现金佣金。当前博客先接一个广告位，优先做与文章内容相关的阿里云推广即可。

## 如何填写广告配置

打开 `src/config.ts`，找到 `SidebarSponsor`。以下例子中的域名、文案和素材路径仅说明格式；不要原样启用。`href` 必须替换成官网后台复制的完整个人推广链接，保留其中所有查询参数。

```ts
SidebarSponsor: {
  enable: true,
  brand: '实际服务商名称',
  title: '后台确认可使用的活动标题',
  description: '后台确认可使用的活动介绍',
  href: 'https://example.com/your-own-campaign-link',
  buttonText: '查看活动',
  image: '/assets/images/ads/campaign.webp',
  imageWidth: 300,
  imageHeight: 600,
},
```

- 图片放到 `public/assets/images/ads/`；`imageWidth` 和 `imageHeight` 填图片真实像素，避免页面加载时跳动。无需追求 300×600，组件会保留图片比例。
- 没有官方图片时，`image: ''` 可以显示文字广告。仍需填写真实品牌、标题和个人推广链接。
- 修改完成后本地构建、预览、提交 GitHub，由 Cloudflare 自动部署。
- 不需要为静态广告部署服务器、数据库或单独统计脚本。返佣由商家的推广平台记录。
- 结束活动时，将 `enable` 改为 `false` 并发布。整张广告卡消失，不会留下空白。

网页会明确显示“广告”以及“推广链接可能产生佣金”，链接在新标签页打开，带 `sponsored` 标记。当前实现不会加载弹窗、底部遮挡或商家提供的任意脚本。

## 发布后核对

1. 桌面和手机都能正常阅读文章，广告没有遮挡导航或正文。
2. 点击广告，打开的是你后台提供的完整推广链接；查询参数没有丢失。
3. 图片没有拉伸，按钮与广告标识清晰。
4. 收到真实客户订单后，在商家后台核对关联与订单归属；单纯点击或跳转检查不能验证返佣到账。
5. 定期检查活动是否到期、素材文案是否变化，按官方要求更新。
