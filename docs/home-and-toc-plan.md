# 首页图片入口与文章目录

用户要求参照九陌斋首页的大图与小图入口，替换自己的首页背景；文章目录放在自己的左侧推荐文章下方。

## 观察与实现选择

- 参考网站 https://blog.jiumoz.com/ 的 DOM 显示 Halo 2.26.1 与 PandaPRO 资源，首页为横向大图及分类图片链接。只采用布局关系，继续使用现有 Astro。
- 新首页：一张 LTZ 自制 3D 技术写作横图，左侧 HTML 自我介绍和文章入口；下面四项图片链接，进入现有博客搭建、路由器、动态、我的链接。
- 配图独立生成并压缩为 WebP，提供移动尺寸。文字由 HTML 呈现，不烘焙进图片。旧原始素材保留用于回退。
- 文章目录从 Astro render 的 headings 生成，支持正文 h1–h3 的实际 slug；左侧 sticky，当前章节高亮，点击避开 66px 固定导航栏。手机在正文前显示可折叠目录。
- Swup 替换整个 main 与导航栏，保证首页大图、目录和侧栏随文章切换更新；页脚保留，统计脚本继续监听页面导航。

## 执行与验证

1. 构建输出集成测试先确认旧版缺少首页图片入口和文章目录。
2. 生成原创配图，完善首页、目录组件与路由初始化。
3. 构建、封面链接检查、目录锚点检查，真实浏览器验证目录点击、滚动高亮、首页→文章→首页及手机布局。
4. 提交推送 main，等待 Pages 成功部署并验证正式网站，保存截图与维护说明。

本地验证记录（2026-10-02）：构建生成 20 页；四项入口与两篇文章目录锚点测试通过；两张文章封面链接测试通过。浏览器确认桌面目录点击后标题距视口顶部约 96px、章节高亮正确；首页→文章→首页及文章之间切换更新目录；390px 手机无横向溢出、使用竖版图片、四入口两列、折叠目录可跳转。发布后仍需核对正式网站。
