你好，我是 **ltz150**，欢迎来到 **LTZ博客**。

这里记录技术实践、学习笔记与日常，把亲手尝试过的配置、问题和解决过程整理下来，方便以后查阅，也分享给遇到同类问题的人。

## 我在记录什么

- **技术实践**：路由器、网络配置和日常使用中的折腾记录。
- **博客搭建**：GitHub、Cloudflare Pages、部署与性能优化的实际步骤。
- **学习与日常**：在 Obsidian 中写下所学，持续积累自己的笔记。

## 这个博客怎么发布

在 Mac 上用 Obsidian 写 Markdown，将需要公开的文章和图片提交到自己的 GitHub 仓库，再由 Cloudflare Pages 自动构建发布。访问统计使用 Cloudflare Web Analytics。

搭建过程见 [从 Obsidian 到个人博客：手动部署指南](/article/obsidian-astro-cloudflare-pages)。
